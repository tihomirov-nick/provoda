# Provoda

Provoda показывает, что подключено к Mac по USB и Thunderbolt. У каждого устройства в списке есть значок типа, имя, протокол со скоростью («USB 3.2 Gen 2 · 10 Гбит/с», «Thunderbolt 4 · 40 Гбит/с»), мощность, если macOS её сообщает, производитель и тип. Серийные номера скрыты, их включают в настройках. Список обновляется сам, когда устройство подключают или отключают, поиск внизу окошка ищет по имени, производителю, типу и скорости.

Provoda живёт в строке меню, значка в Dock у него нет. Щелчок по значку открывает окошко приложения. Правый щелчок или щелчок с Control открывает меню: действия приложения, «Настройки…» ⌘,, «Проверить обновления…», «О приложении «Provoda»» и «Завершить Provoda» ⌘Q.

## Что меняет приложение

Своё приложение пишет в `Sources/Provoda/AppParts.swift`, остальной код в `Sources/Provoda` общий для семьи.

1. Знак. `MenuBarIcon.drawGlyph` рисует его линиями в строке меню, `drawMark` в `scripts/make_icon.swift` рисует его белым на чёрной плитке иконки. В строке меню знак 16 pt высотой на холсте 22 pt, как у системных значков, на иконке занимает 80% плитки (рамка его чернил `ProvodaMark.bounds`, те же числа лежат в `scripts/make_icon.swift`, и тест их сверяет), линии растут вместе со знаком. После правки иконку пересобирает `swift scripts/make_icon.swift`.
2. Главное окошко `MainView`, содержимое чёрной панели под значком. Ширина 276 pt, высота по содержимому.
3. Раздел настроек `AppSettingsSection` под «Основными» и «Обновлениями». Строки собираются из `SectionTitle`, `SwitchRow`, `Row` с `MenuCapsule` и `Separator`, как в `SettingsWindow.swift`.
4. Действия меню `AppActions.menuItems()`. Они встают над «Настройки…», разделитель меню ставит само, пункт из замыкания делает `ClosureMenuItem`.
5. Занятость `AppActions.isBusy`. Пока приложение занято (идёт таймер, пишется файл), обновление ждёт и не перезапускает его, кнопка «Перезапустить» для нового языка тоже недоступна.

## Как устроен список

USB-устройства Provoda берёт из I/O Registry, это объекты `IOUSBHostDevice`. Имя идёт из `kUSBProductString`, скорость из `UsbLinkSpeed` (без него из кода `Device Speed`), мощность из `UsbPowerSinkAllocation`, ток в миллиамперах при 5 В. Если устройству не хватило питания, под ним появляется предупреждение из `kUSBFailedRequestedPower`. Тип определяется по классам интерфейсов и имени. Thunderbolt и USB4 приходят из `IOThunderboltSwitch`: поколение по версии роутера, скорость по текущей скорости и ширине линии порта, к которому он подключён. Собственные контроллеры Mac (глубина 0) в список не попадают. О подключении и отключении сообщает `IOServiceAddMatchingNotification`, через 0,4 с Provoda перечитывает реестр.

Хабы и внутренние устройства Mac по умолчанию скрыты переключателем «Скрывать встроенные хабы». Уведомление о новом устройстве включается в настройках, разрешение macOS спрашивает в момент включения.

Разбор свойств лежит в `Sources/ProvodaCore` и проверяется тестами на снятых словарях свойств, живое железо им не нужно.

## Сборка

```sh
swift build && swift test            # тесты не трогают строку меню и ничего не регистрируют
./scripts/build_app.sh               # build/Provoda.app, универсальная сборка
ARCHS=arm64 ./scripts/build_app.sh   # быстрее, только для этого Mac
```

`build_app.sh` подписывает приложение сертификатом «tihomirov-nick» (SHA-1 `AF82036140843A7D76497EA8E4CD23403C8AEDC2`), если он есть в Связке ключей, иначе ad-hoc. Установленная копия обновляется только до версии с той же подписью.

Тексты интерфейса пишутся по-русски через `L("…")`, русская строка служит ключом. Английский перевод лежит в `scripts/l10n/en.json`, из него `scripts/l10n/make_strings.py` делает `Resources/en.lproj/Localizable.strings`. Если у строки нет перевода, сборка падает, а `swift test` замечает это ещё раньше.

`swift run Provoda --list-devices` печатает в терминал список с этого Mac, серийные номера закрыты точками. `swift run Provoda --render-previews /tmp/preview` рисует в один файл `preview.png` окошко с вымышленными устройствами, его же с серийными номерами и хабами, настройки и значок, ничего не показывая на экране.

## Выпуск

```sh
VERSION=1.0.0 ./scripts/make_dmg.sh                          # dist/Provoda-1.0.0.dmg
VERSION=1.0.0 NOTES=~/notes-1.0.0.md ./scripts/release.sh    # тег, push и релиз на GitHub
```

В DMG лежат приложение, ссылка на «Программы» и инструкции «Как установить.txt» и «How to install.txt». Приложение открывают прямо из окна DMG, и оно само переезжает в «Программы». `release.sh` собирает только закоммиченный код ветки main, берёт токен из Связки ключей (аккаунт `tihomirov-nick`, сервис `github-provoda-token`) и выкладывает релиз в `tihomirov-nick/provoda`. Git ходит туда по HTTPS: скрипт сам прописывает `origin` и помощника учётных данных с тем же токеном, потому что глобальный помощник git настроен на другой аккаунт. Перед push он проверяет, что приложение в DMG подписано «tihomirov-nick». Версия по умолчанию записана в `build_app.sh` и `make_dmg.sh`.

## Общие файлы семьи

Эти четыре файла одинаковы во всех приложениях семьи, байт в байт. Их правят в Subline и разносят копированием со сверкой sha256.

- `Sources/Provoda/Updater.swift` ищет новый релиз на GitHub при запуске, раз в три часа и после пробуждения Mac. Новую версию он ставит сам, когда приложение свободно (`appIsBusy`), или предлагает её (`freshOffer`). Перед установкой сверяет подпись скачанной версии с подписью установленной.
- `Sources/Provoda/Updater+Placement.swift` переносит копию, открытую из DMG или «Загрузок», в /Applications (без прав администратора в ~/Applications) и перезапускает её оттуда.
- `Sources/Provoda/Updater+LoginItem.swift` включает запуск при входе через `SMAppService` один раз для копии в «Программах», дальше решает пользователь. `LoginItem.launchedAtLogin` говорит, что приложение открылось при входе в систему.
- `Sources/ProvodaCore/InterfaceLanguage.swift` хранит язык интерфейса по стандарту семьи. «Как в системе», «Русский» и «English» пишутся в собственный `AppleLanguages` приложения, это та же настройка, что в Системных настройках. Чтение и запись делают `saved` и `save`, про перезапуск отвечают `needsRestart` и `relaunch`.

Общее для семьи, но со своими текстами: `SoundEffects.swift` (системные звуки семьи и переключатель «Звуковые эффекты»), `Updates.swift` (состояния обновления, точка на значке и карточка в окошке), `SettingsWindow.swift`, `StatusItem.swift`, `MainMenu.swift` (невидимое главное меню с «Правкой», чтобы в полях работали ⌘C, ⌘V, ⌘A и ⌘Z) и `Style.swift`.
